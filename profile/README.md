# Net F/T

Independent open-source libraries and ROS drivers for ATI Net F/T Ethernet force/torque sensors.

## Projects

| Project | Ecosystem | Purpose |
| --- | --- | --- |
| [netft-cpp](https://github.com/netft/netft-cpp) | C++ | Native library and command-line tools |
| [pyNetFT](https://github.com/netft/pyNetFT) | Python | Python access to Net F/T sensors |
| [ros-netft](https://github.com/netft/ros-netft) | ROS 1 and ROS 2 | ROS drivers and `ros2_control` integration |

## Support

Please report bugs or request features in the issue tracker of the relevant project.

## Independence

These projects are community-maintained and are not affiliated with ATI Industrial Automation.
